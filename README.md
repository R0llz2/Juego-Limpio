# Juego Limpio: ¿quién decide las reglas del juego?

Material didáctico digital de ética y competencias ciudadanas para estudiantes de **grado cuarto** (9 a 10 años). Aborda un problema concreto de la vida escolar: **la exclusión de compañeros en el juego mediante reglas que impone el grupo que controla el juego**.

**▶ Jugar:** https://r0llz2.github.io/Juego-Limpio/

## Qué contiene

- **El caso del balón:** un dilema sin respuesta única que abre la secuencia con una primera postura y la cierra con su revisión ante información nueva.
- **Nivel 1 · Escáner de derechos:** ¿el derecho está cuidado o en riesgo? Incluye Mito o verdad.
- **Nivel 2 · Detective del recreo:** encontrar la exclusión en un patio, reconocer emociones y ayudar sin agredir.
- **Nivel 3 · Duelo de jugadas:** comparar alternativas por sus consecuencias para las dos partes.
- **Nivel 4 · Asamblea final:** reglas impuestas, acuerdos y normas de autoridad; medidor de regla justa y pacto del curso.
- **Herramientas para el docente:** guía dentro de cada actividad, cronómetro, sorteo de equipos, lista de cotejo y resultados del curso. La clave de acceso está en la guía docente.

## Cómo usarlo

- En línea: abra el enlace de arriba en Chrome, Edge, Firefox o Safari.
- Sin internet: descargue `index.html` y ábralo con doble clic. Todo funciona sin conexión.
- En clase se recomienda proyectarlo con el **modo proyector** y trabajar en equipos de 4 o 5.
- La app no envía datos a ningún servidor: el avance y los resultados se guardan solo en el navegador del dispositivo.

## Código fuente

La carpeta `codigo-fuente` contiene los archivos con los que se genera `index.html`:

```bash
cd codigo-fuente
npm install
npm run build      # genera dist/juego-limpio.html
```

Para publicar una nueva versión, reemplace `index.html` por el archivo generado.
